# Agent Pipeline

`yread` has three conceptual steps: a lightweight profile identifies project shape, the Catalog Agent plans architecture-first topics, and Page Agents gather evidence before writing each page.

| Step | Input | Output |
| --- | --- | --- |
| Profile | Repository files | Project shape and depth signal |
| Catalog | Repository structure, profile, key files | V2 topic catalog |
| Page | One page task, evidence paths, navigation context | Markdown document |

This static sample demonstrates the output layout. It is not a real model-generated run.
